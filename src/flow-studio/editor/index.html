Tu proceso, con claridad.

Añade figuras desde la izquierda y arrástralas sobre el lienzo. Selecciona una figura para editar su texto, tamaño y color.

Para conectar: pulsa C, elige origen y destino. Selecciona una flecha para escribir condiciones como Sí o No. Haz doble clic en una figura para editar el texto.

Usa la rueda para desplazar el lienzo; Ctrl + rueda cambia el zoom. Guarda JSON para continuar en otro equipo y exporta SVG para compartir o imprimir.
